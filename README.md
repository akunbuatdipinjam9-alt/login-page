# Elsewhere — Coastal Login Page

Open `index.html` in any modern browser. The coastal image is included locally in `assets/coast.png`; no build or dependencies are needed. Google Fonts are optional and require internet access.

This is a **front-end demo**. Email/password submit validates the input locally but does not authenticate, send, or store credentials. Google, registration, and password reset are clearly non-functional demos. Connect a secure authentication provider/backend before deploying a real login service.

Files: `index.html`, `styles.css`, `script.js`, `assets/coast.png`.
